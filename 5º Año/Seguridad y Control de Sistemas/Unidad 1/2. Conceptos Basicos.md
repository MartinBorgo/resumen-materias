## Tipos de Atacantes
- **Crackers**: Personas que se dedican a romper sistemas de seguridad con fines maliciosos. Utilizan ingeniería inversa para crear programas que eliminen las protecciones del software o ingresan ilegalmente a sistemas protegidos para obtener información, borrar datos u obtener beneficios económicos. La principal deferencia entre estos y los hackers son sus intenciones maliciosas.
- **Defacers**: Atacantes que se especializan en *desfigurar páginas web* explotando vulnerabilidades del servidor o errores de programación. Su objetivo principal es colocar propaganda o hacer públicas sus protestas, generalmente atacando sitios web de alto tráfico como páginas gubernamentales, instituciones educativas o empresas importantes.
- **Hackers**: Expertos en seguridad informática con grandes conocimientos técnicos que investigan y aprenden de manera permanente. Se caracterizan por tomar control de sistemas altamente protegidos únicamente para desafiarse a sí mismos y aumentar sus conocimientos, sin buscar reconocimiento público ni causar daños intencionalmente.
- **Script Kiddies o Script Boys**: Personas con pocos o nulos conocimientos de programación y seguridad informática que utilizan *scripts* o *exploits* creados por otros para comprometer sistemas con poca seguridad. Su motivación principal es el reconocimiento público, dedicando más tiempo a alardear que a aprender realmente.
- **Viruxers**: Programadores especializados en crear virus informáticos con el objetivo de infectar sistemas. Los virus que desarrollan pueden tener características y riesgos muy diversos, desde simples molestias hasta amenazas destructivas.
## Técnicas de Ataque
- **Phishing**: Técnica de ingeniería social utilizada para obtener información confidencial como contraseñas, datos bancarios o información personal. Se ejecuta principalmente mediante correos electrónicos falsos que imitan páginas auténticas de bancos, empresas o servicios, engañando al usuario para que revele sus datos.
- **Ingeniería social**: Arte de manipular personas para eludir los sistemas de seguridad. Los atacantes se aprovechan de la confianza y la inocencia de los usuarios, haciéndose pasar por compañeros de trabajo, técnicos o administradores para obtener información que les permita realizar ataques más complejos.
- **Spoofing (Suplantación de identidad)**: Técnica que consiste en falsificar la identidad en diferentes elementos de la red:
	- **Spoofing de IP**: Suplantar la dirección de origen de un paquete para que el destino crea que proviene de un servidor confiable.
	- **Spoofing de DNS**: Reemplazar la asociación IP-dominio en servidores DNS para redirigir usuarios a sitios maliciosos.
	- **Spoofing de DHCP**: Suplantar el servidor DHCP de una red para controlar las direcciones IP asignadas.
- **Exploits**: Fragmentos de código diseñados específicamente para aprovechar vulnerabilidades de sistemas informáticos, generando comportamientos no deseados. Permiten acceso no autorizado, escalada de privilegios o ataques de denegación de servicio. Los ***exploits 0-day*** son especialmente peligrosos porque utilizan vulnerabilidades aún desconocidas.
- **Denegación de servicio (DoS/DDoS)**: Ataque dirigido a afectar el funcionamiento normal de sistemas informáticos mediante técnicas como saturación de recursos, bloqueo de cuentas de usuario o aprovechamiento de errores de programación. La variante distribuida (DDoS) utiliza redes de computadoras zombies (Botnets) para realizar ataques más potentes y difíciles de detectar.
## Sistemas de Protección
- **Firewall**: Sistema ubicado entre el internet y la red interna de una organización, este tipo de sistemas implementa diferentes políticas de seguridad establecidas por la organización. Actúa como barrera protectora monitoreando el tráfico de red, generando alarmas ante intentos de ataque y siendo el punto central para supervisar la seguridad de la red.
- **Sistema de prevención de intrusos (IPS)**: Sistema que ejerce control proactivo sobre las actividades realizadas en el sistema protegido. Intenta impedir el acceso de intrusos y, en caso de detectar amenazas, toma acciones automáticas para bloquearlas o limitar su impacto antes de que causen daño.
- **Sistema de detección de intrusos (IDS)**: Programa que analiza redes o computadoras para detectar supuestos intrusos basándose en patrones de actividades sospechosas. Utiliza sensores virtuales para monitorear el tráfico, comportamiento y contenido de la red, realizando una protección reactiva que responde una vez detectado el ataque.

>[!tldr] Diferencia entre IDS e IPS
>La principal diferencia entre IPS e IDS es que el IPS previene, es decir realiza acción proactiva para asegurar el sistema, mientras que el IDS detecta y responde, osea toman acciones reactivas.
