## Multiplicación de Enteros Grandes
Supongamos que tenemos que multiplicar dos enteros $a$ y $b$, de $n$ y $m$ dígitos, los cuales no pueden ser representados directamente en el hardware de la máquina. Si se implementa cualquiera de los algoritmos tradicionales para el producto entre dos números, el resultado es del orden $\Theta(mn)$. En caso de que $n = m$ el orden pasa a ser cuadrático en vez de lineal.
Considerando que la operación de multiplicación es mucho más costosa que las operaciones de suma o de resta, lo que se intenta lograr es aplicar la técnica de dividir y conquistar para intentar disminuir la cantidad de operaciones involucradas en la resolución de este problema. Uno de los enfoques más comunes es particionar a la mitad los números, por ejemplo:
- $a = 981 \rightarrow w = 9, x = 81 \rightarrow a = 10^2w + x$
- $b = 1234 \rightarrow y = 12, z = 34 \rightarrow a = 10^2y + z$

Teniendo esto presente, el producto entre dos números puede computarse de la siguiente manera:
$$
\begin{align*}
981 \times 1234 
  &= (10^2 w + x) \times (10^2 y + z) \\
  &= 10^4 wy + 10^2 (wz + xy) + xz \\
  &= 1080000 + 127800 + 2754 = 1210554
\end{align*}
$$
Lo único que se hizo hasta ahora es redefinir el algoritmo anterior, pero aun así necesitamos cuatro multiplicaciones para llegar al resultado. Con un pequeño cambio en este método podemos ahorrarnos una de estas multiplicaciones llevando adelante la siguiente operación:
$$
r = (w + x) \times (y + z) = wy + (wz + xy) + xz
$$
Teniendo esto en cuenta podemos reestructurar el procedimiento de la siguiente manera:
$$
a \times b = 10^4p + 10^2(r-p-q) + q
$$
En donde $p$ es $wy$ y $q$ es $xz$. De esta forma podemos realizar el procedimiento utilizando solo tres multiplicaciones y un conjunto de sumas, restas y desplazamientos.
En el ejemplo solo se aplica la estrategia dividir y conquistar una única vez, pero los problemas reales requieren de muchas más recursiones hasta llegar a instancias pequeñas. Por lo tanto, para el tiempo del algoritmo se genera una recursión del tipo
$$
t_{DyC} = 
\begin{cases}
\Theta(n^2) & \text{si $n$ es pequeño} \\
3t_{DyC}(n/2) & \text{si $n$ es grande}
\end{cases}
$$
Aplicando el teorema maestro podemos llegar a la conclusión de que $t_{DyC}(n) \in \Theta(n^{lg\ 3})$. Como $lg \ 3$ es menor que dos, el algoritmo antes expuesto es más eficiente que una multiplicación clásica.
## Multiplicación de Matrices
Dadas dos matrices $A$ y $B$ sí se quiere realizar una multiplicación entre ambas matrices, la forma tradicional de realizar esta operación nos da un tiempo de orden $\Theta(n^3)$. Existe un algoritmo que nos permite ahorrar una multiplicación extra, este es conocido como el método de Strassen.
Supongamos que $A$ y $B$ son dos matrices cuadradas de 2x2, que contienen los siguientes elementos:
$$
A =
\begin{pmatrix}
a_{11} & a_{12} \\
a_{21} & a_{22}
\end{pmatrix} \quad
B =
\begin{pmatrix}
b_{11} & b_{12} \\
b_{21} & b_{22}
\end{pmatrix}
$$
El algoritmo de Strassen descompone las operaciones que se realizan en siete en vez de ocho:
- $m_1 = (a_{11} + a_{22}) \times (b_{11} + b_{22})$
- $m_2 = (a_{21} + a_{22})\times b_{11}$
- $m_3 = (b_{12} - b_{22}) \times a_{11}$
- $m_4 = (b_{21} - b_{11}) \times a_{22}$
- $m_5 = (a_{11} + a_{12})\times b_{22}$
- $m_6 = (a_{21} - a_{11})\times (b_{11} + b_{12})$
- $m_7 = (a_{12} - a_{22})\times (b_{21} + b_{22})$

En este caso, el resultado de $A \times B$ va a ser una matriz $C$ cuyos elementos serán el resultado de las siguientes operaciones:
$$
C =
\begin{pmatrix}
m_1 + m_4 - m_5 + m_7 & m_3 + m_5 \\
m_2 + m_4 & m_1 - m_2 + m_3 + m_6
\end{pmatrix}
$$
Aunque este método introduce más sumas y restas, la reducción de multiplicaciones es crucial porque, en primer lugar las multiplicaciones son operaciones más costosas que las sumas y además al aplicar recursivamente este enfoque a matrices más grandes, el ahorro se vuelve significativo.
Este enfoque se puede aplicar recursivamente dividiendo las matrices de $n\times n$, donde $n$ es potencia de dos, en cuatro sectores de los cuales se resuelven utilizando el método antes descritos.
A grandes rasgos, el tiempo que le toma a este método, resolver una matriz de $n \times n$ está dada por:
$$
t(n) =
\begin{cases}
\Theta(n^2) & \text{si la instancia es pequeña} \\
7\cdot t(n/2) + g(n) & \text{si la instancia es grande}
\end{cases}
$$
Cabe recalcar que $g(n) \in \Theta(n^2)$. Por lo tanto, el método de Strassen pertenece al orden $O(n^{lg \ 7})$ el cual es mejor que el orden cúbico del método tradicional.
A lo largo del tiempo surgieron mejoras al método de Strassen que mejoran mucho más la eficiencia del algoritmo, pero los costos encubiertos de estos métodos hacen que en la práctica sean inaplicables.
## Búsqueda Binaria
Dados un arreglo de enteros ordenados en forma no decreciente y un entero $x$, se quiere encontrar el índice $i$ tal que $T[i – 1] < x \leq T[i]$. Es decir, lo que se quiere es encontrar el entero $x$ en el arreglo, y si no existe, queremos saber en qué posición del arreglo debería ser insertado.
La forma más sencilla de resolver este problema es recorriendo el arreglo posición por posición hasta llegar al elemento en cuestión, el peor caso y el caso promedio de este algoritmo pertenece al orden $\Theta(n)$, mientras que el mejor caso al orden $\Theta(1)$.
Este tiempo se puede mejorar aplicando una búsqueda binaria, si bien este algoritmo no perteneces puramente al grupo de algoritmos de dividir y conquistar es una modificación especial del método, dado que solo maneja una única instancia, la cual se va achicando en cada recursión, a este tipo de casos se los denomina ***simplificación***. Este algoritmo utilizando recursión es simple:
```python
def binary_search(xs, x):
	# Funcion recursiva
	def recursion_function(xs, x, i, j):
	    if i == j:
	        return i + 1
	    
	    k = (i + j) // 2
	    
	    if x <= xs[k]:
	        return recursion_function(xs, x, i, k)
	    else:
	        return recursion_function(xs, x, k + 1, j)
		
    
    if len(xs) == 0 or x > xs[-1]:
        return len(xs) + 1
    else:
        return recursion_function(xs, x, 0, len(xs) - 1)
```

Este algoritmo recursivo puede reescribirse para generar uno iterativo, ya que las llamadas recursivas se encuentran al final del algoritmo.
Sea $m = j - 1 + 1$ el tiempo de ejecución de la búsqueda binaria está dada por la siguiente recursión:
$$
t(m) =
\begin{cases}
a & \text{si $m = 1$} \\
b + t(n/2) & \text{si $m \neq 1$}
\end{cases}
$$
Si aplicamos el teorema maestro obtenemos que la búsqueda binaria pertenece al orden $\Theta(lg \ m)$.
## Ordenamiento
Existen varios algoritmos clásicos de ordenamiento que siguen el modelo de dividir y conquistar, como es el caso del *mergesort* y el *quicksort*.
### Mergesort
Este tipo de algoritmos divide la instancia original en dos instancias de tamaño similar, las ordena y una vez ordenadas se las combina para obtener la instancia original pero ordenada.
```python
def mergesort(xs):
	# Algoritmo de mezcla
	def mix(us, vs):
    i, j = 0, 0
    result = []
    
    while i < len(us) and j < len(vs):
        if us[i] < vs[j]:
            result.append(us[i])
            i += 1
        
        else:
            result.append(vs[j])
            j += 1
    
    result.extend(us[i:])
    result.extend(vs[j:])
    
    return result

```

El tiempo de ejecución del mergesorte está dada por la siguiente recursión
$$
t(n) =
\begin{cases}
n^2 & \text{si $n$ es pequeño} \\
t(\lfloor n/2 \rfloor) + t(\lceil n/2 \rceil) + g(n) & \text{si $n$ es grande e impar} \\
2t(n/2) + g(n) & \text{si $n$ es grande y par}
\end{cases}
$$
En este caso $g(n) \in \Theta(n)$, por lo que si se aplica el teorema maestro obtendremos que el mergesort pertenece al orden de $\Theta(n \cdot log \ n)$, con la desventaja de que este algoritmo necesita espacio adicional para almacenar las subinstancias, además la eficiencia del mismo se garantiza si las subinstancias poseen tamaño similar, de lo contrario su rendimiento decrecerá siendo incluso peor que el ordenamiento por inserción.
### Quicksort
A diferencia del mergesort, la mayor porción de la parte no recursiva del trabajo a realizar se utiliza construyendo las subinstancias, y no combinando sus soluciones. Este algoritmo utiliza un pivote
Este algoritmo seleccionar un elemento del arreglo como *pivote* y reorganizar todos los demás elementos en dos grupos: 
1. Los elementos menores al pivote se ubican a la izquierda del mismo.
2. Los elementos mayores al pivote se ubican a la derecha del mismo.

Una vez completada esta partición, el pivote queda ubicado en su posición definitiva. El algoritmo continúa aplicando el mismo proceso recursivamente a cada uno de los dos subarreglos resultantes hasta que estos sean suficientemente pequeños para resolverlos mediante un método más simple como el ordenamiento por inserción.
El proceso de pivoteo comienza con dos punteros situados en los extremos del arreglo que avanzan hacia el centro. El puntero izquierdo avanza hasta encontrar un elemento mayor que el pivote, mientras el derecho retrocede hasta hallar uno menor. Si los punteros no se han cruzado, se intercambian ambos elementos y se continúa el proceso. Si ambos punteros se cruzan, se intercambia el pivote con el elemento del puntero derecho, colocándose el pivote en su posición correcta, completando así la partición. Luego se ordena recursivamente ambos lados del pivote hasta que el arreglo esté completamente ordenado.
```python
def quicksort(xs):
	# Metodo que permite realiza el pivoteo
	def pivoting(xs, i, j):
    p = xs[i]
    k = i
    l = j + 1
    
    while True:
        k += 1
        while k <= j and xs[k] <= p:
            k += 1
            
        l -= 1
        while xs[l] > p:
            l -= 1
            
        if k >= l:
            break
            
        xs[k], xs[l] = xs[l], xs[k]
    
    xs[i], xs[l] = xs[l], xs[i]
    
    return l
	
	# Metodo que permite resuelve el llamado de forma recursiva
	def recursive_quicksort(xs, i, j):
	    if j - i <= 4:
		    # Este procedimiento ordena un subarreglo
	        insertion_sort(xs, i, j)
	    else:
	        l = pivoting(xs, i, j)
	        
	        recursive_quicksort(xs, i, l - 1)
	        recursive_quicksort(xs, l + 1, j)
	
    xs = xs.copy()
    recursive_quicksort(xs, 0, len(xs) - 1)
    
    return xs
```

La eficiencia de este algoritmo varía significativamente según las características de los datos. En el peor caso, cuando las particiones resultan extremadamente desbalanceadas, su complejidad es $O(n^2)$. Sin embargo, en el caso promedio, este algoritmo exhibe un rendimiento de $O(n \cdot log \ n)$, lo que lo convierte en un algoritmo altamente eficiente con constantes ocultas menores que otros métodos de ordenamiento de la misma complejidad teórica.
La eficiencia de este algoritmo se puede aumentar si se aplican optimizaciones como lo podría ser:
- La elección de una estrategia de pivoteo más eficiente (como la mediana).
- El establecimiento de umbrales para cambiar a algoritmos más simples con arreglos pequeños.
- La implementación de partición en tres vías para manejar eficientemente elementos iguales.
## Exponenciación
La exponenciación consiste en calcular potencias del tipo $x = a^n$, donde $a$ y $n$ son números enteros. El algoritmo más simple para este cálculo realiza $n-1$ multiplicaciones sucesivas, resultando en una complejidad de $\Theta(n)$. Sin embargo, este enfoque directo se vuelve problemático cuando el resultado es grande, lo que causa un desbordamiento incluso con valores relativamente pequeños.
Para mejorar la eficiencia y manejar enteros grandes, aprovechando la propiedad de que $a^n = (a^{n/2})^2$ cuando $n$ es par. La idea fundamental consiste en reducir el problema a la mitad recursivamente y utilizar el cuadrado para reconstruir el resultado original. Cuando $n$ es impar, simplemente calculamos $a\cdot a^{n-1}$. Esta estrategia reduce dramáticamente el número de multiplicaciones necesarias, poseyendo una complejidad de $\Theta(log \ n)$. El algoritmo recursivo es el siguiente:
```python
def expoDyC(a, n):
	if n == 0 return 1

	if n % 2 == 0:
		return expoDyC(a, n / 2)
	else:
		return expoDyC(a, n - 1)
```

Tal y como se puede apreciar en el código, la recurrencia del algoritmo de exponenciación que utiliza simplificación está dada por la siguiente función
$$
N(n) =
\begin{cases}
0 & \text{si $n = 1$} \\
N(n/2) & \text{si $n$ es par} \\
N(n-1) + 1 & \text{si $n$ es impar}
\end{cases}
$$
Al resolver esta recurrencia obtenemos que este algoritmo pertenece al orden $\Theta(log \ n)$. Si también tenemos en cuenta el tiempo consumido por las multiplicaciones, el cual dependerá de si se utiliza el método clásico y el basado en las técnicas de dividir y conquistar, en tal caso obtendremos los siguientes rendimientos:

|       Algoritmo de Exponenciación       | Multiplicación Clasica | Multiplicación Dividir y Conquistar |
| :-------------------------------------: | :--------------------: | :---------------------------------: |
|        Exponenciación Secuencial        |    $\Theta(m^2n^2)$    |       $\Theta(m^{lg \ 3}n^2)$       |
| Exponenciación con Dividir y Conquistar |    $\Theta(m^2n^2)$    |   $\Theta(m^{lg \ 3}n^{lg \ 3})$    |
Esta tabla muestra el tiempo de calcular $a^n$, en donde $m$ representa el tamaño de $a$.
### Exponenciación Modular
La exponenciación modular es una variante especializada para la aritmética modular, calcula $a^n \ mod \ z$. Esta operación es crucial en criptografía y tiene la propiedad fundamental de que nunca es necesario manejar números mayores que $z^2$ durante el cálculo.
La aplicación más relevante de la exponenciación modular se encuentra en la criptografía de clave pública, específicamente en el sistema RSA. Este sistema se basa en la dificultad computacional de factorizar números grandes y en la facilidad relativa de calcular exponenciaciones modulares. Para cifrar un mensaje, se utiliza una clave pública $(n,z)$ para calcular $c = a^n \ mod \ z$. Para descifrar, se usa una clave privada $s$ para calcular $a = c^s \ mod \ z$. La seguridad del sistema reside en que, aunque un atacante conozca $c$, $z$ y $n$, calcular la raíz n-ésima modular es computacionalmente inviable sin conocer la factorización de $z$.
>[!note] Bases del Sistema RSA
>Este sistema funciona de manera correcta, ya que hace uso de dos propiedades fundamentales del álgebra modular:
>1. $xy \ mod \ z = [(x \ mod \ z) × (y \ mod \ z)] \ mod \ z$
>2. $(x \ mod \ z)^y mod z = x^y \ mod \ z$

La exponenciación modular puede ejecutar cálculos con números extremadamente grandes en tiempos razonables, mientras que los enfoques directos requerirían tiempos equivalentes a múltiples veces la edad del universo. Esta extraordinaria eficiencia, combinada con la dificultad de invertir el proceso, ha convertido al RSA en uno de los avances más importantes en la historia de la criptografía, permitiendo comunicaciones seguras en la era digital sin coordinación previa entre las partes. A grandes rasgos, el algoritmo de exponenciación modular es el siguiente:
```python
def expomod(a, n, z):
	i, r, x = n, 1, a % z
	while i < 0:
		if i % 2 != 0:
			r = x*r % z
		
		x = x**2 % z
		i = i // 2
	
	return r
```
