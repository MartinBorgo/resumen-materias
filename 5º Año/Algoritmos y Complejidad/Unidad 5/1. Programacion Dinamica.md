La programación dinámica es una técnica para resolver problemas complejos evitar calcular la misma subinstancia varias veces. Para lograrlo, se almacenan los resultados de cada subproblema en una tabla que se va completando a medida que se avanza en la resolución, mejorando así la eficiencia del algoritmo.
A diferencia de la estrategia [[1. Dividir y Conquistar|dividir y conquistar]] que trabaja de forma descendente (top-down) atacando primero el problema completo, dividiéndolo en partes más pequeñas. La programación dinámica utiliza un enfoque ascendente (bottom-up), resolviendo los subproblemas más pequeños y simples, y luego combina estas soluciones para resolver problemas progresivamente más grandes hasta alcanzar la solución de la instancia original. Este enfoque se utiliza principalmente en problemas de optimización donde la solución se forma mediante una serie de decisiones interconectadas.
Para la aplicación de este enfoque se deben asegurar que el problema en cuestión cumpla con los siguientes requisitos:
1. **Principio de optimalidad de Bellman**: La solución óptima debe contener soluciones óptimas a sus subproblemas.
2. **Superposición de subproblemas**: Los subproblemas derivados del problema inicial se repiten varias veces durante el proceso de resolución.

>[!tldr] Aspectos a Definir al Momento de Crear un Algoritmo de Programación Dinámica
>Al momento de resolver problemas utilizando implementando algoritmos que hagan uso de este enfoque, se debe definir una serie de cuestiones, entre las cuales se encuentran:
>- Ecuación recurrente que construya la solución al problema inicial a partir de los resultados obtenidos de resolver los subproblemas.
>- Identificar los caso base.
>- Definir la tabla que utilizará el algoritmo y como la misma será rellenada.
>- Definir el método que se utilizará para obtener la solución global a partir de los valores de la tabla.
