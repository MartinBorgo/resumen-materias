Cuando hablamos de ***programación lineal***, utilizamos el término programación para hacer referencia a la planeación. Se dice que es lineal porque todas las funciones matemáticas que conforman el modelo son funciones lineales.
El tipo más común de aplicación de este tipo de modelos consiste en resolver problemas de optimización relacionados con la asignación de recursos limitados a distintas actividades que compiten entre sí por ellos. Aunque cualquier problema cuyo modelo matemático se ajuste al formato general de un modelo de programación lineal, es por ende un problema de programación lineal.
A grandes rasgos podemos decir que la programación lineal es un caso particular de modelo de toma de decisiones con restricciones, o modelo de optimización con restricciones, donde se busca la asignación de recursos escasos de forma que se optimice un objetivo de interés. Cada uno de estos modelos tiene dos características importantes:
 - Una función objetivo que se debe maximizar o minimizar.
 - Un conjunto de una o más restricciones.

>[!tldr] Formulación de Modelos de Programación Lineal
>A la hora de formular este tipo de modelos se sigue una seria de pasos:
>1. Identificar las variables del problema, también conocidas como *actividades*.
>2. Construir la función objetivo, definiendo los coeficientes de la función y definiendo si lo que se busca es maximizar o minimizar esta misma.
>3. Expresar las restricciones, determinando los coeficientes o taza de consumo de cada restricción, el signo de la restricción ($<, >, \leq, \geq$), el lado derecho o disponibilidad de cada recurso y si se aplican restricciones de no negatividad sobre las variables intervinientes.
## Forma Estándar del Modelo de Programación Lineal
Podemos decir entonces que un modelo de programación lineal está compuesto por una función objetivo $Z$ que posee la siguiente forma:
$$
Z = c_1x_1 + c_2x_2 + \cdots + c_nx_n
$$
La cual se intenta maximizar o minimizar. Esta función objetivo está sujeta a una serie de restricciones del tipo:
$$
\begin{array}{r@{\;}c@{\;}l}
a_{11}x_{1}+a_{12}x_{2}+\cdots+a_{1n}x_{n} & \le & b_{1}\\
a_{21}x_{1}+a_{22}x_{2}+\cdots+a_{2n}x_{n} & \le & b_{2}\\
                                           & \vdots & \vdots\\
a_{m1}x_{1}+a_{m2}x_{2}+\cdots+a_{mn}x_{n} & \le & b_{m}
\end{array}
$$
Sobre las variables a optimizar y un conjunto de restricciones de no negatividad sobre las variables conforman el problema:
$$
x_1 \geq 0, x_2 \geq 0, \cdots, x_n \geq 0
$$
>[!tldr] Formas Alternativas y Válidas de Modelos de Programación Lineal
>Para problemas que no se refieren a la asignación de recursos limitados a actividades que compiten por ellos, pueden surgir distintos submodelos variantes que posean alguna de las siguientes características
>- Minimizar la función objetivo.
>- Algunas restricciones funcionales poseen el signo $\geq$.
>- Algunas restricciones funcionales pueden estar expresadas como ecuación.
>- Algunas variables de decisión puede que aparezca son la restricción de no negatividad.
## Supuestos de la Programación Lineal
Este tipo de modelos cuenta con una serie de supuestos que deben ser tenidos en cuenta a la hora de establecer que variables y datos se utilizan para la modelación del problema. Estos supuestos son los siguientes:
- **Proporcionalidad**: Este supuesto elimina cualquier exponente diferente de 1 para las variables en cualquier término de las funciones. Es decir, todas las variables que componen el modelo tienen exponente 1. 
- **Aditividad**: Cada función de un modelo de programación lineal es la suma de las contribuciones individuales de las actividades respectivas. Este supuesto elimina los términos de productos cruzados de dos o más variables.
- **Divisibilidad**: Las variables de decisión pueden tomar cualquier valor, incluso valores no enteros, que satisfagan las restricciones funcionales y de no negatividad.
- **Certidumbre**: Los valores asignados a cada parámetro (variable) de un modelo de programación lineal son constantes conocidas, es decir, no cambian con el tiempo o ante situaciones específicas.
## Resolución de los Modelos de Programación Lineal
Se pueden resolver los modelos de programación lineal de diversas maneras, pero algunas de las más comunes son:
- Solución gráfica.
- Método simplex.
### Solución Gráfica
Es el método más simple de resolución y consiste en graficar la función objetivo y las restricciones en un sistema de coordenadas y ver el punto o puntos en el que todas las rectas del modelo se cortan simultáneamente. Véase la siguiente imagen.

Como se puede ver en el punto (2, 2) intercepción de las tres rectas que componen el modelo, siendo la recta roja la correspondiente a la función objetivo y las azules las restricciones a la función objetivo. La principal limitación de este método radica en el hecho de que solo puede resolver problemas cuyas función objetivo y restricciones tenga solo dos variables.
>[!note] Terminología Importante en la Solución del Modelo
>Cualquier conjunto de variables de decisiones ($x_1, x_2, \dots, x_n$) recibe el nombre de ***solución***, aunque puede que estas soluciones no sean las deseadas o realizables. Esto significa que tenemos distintos tipos de soluciones, estas pueden ser:
>- **Soluciones factibles**: Son las soluciones que satisfacen todas las restricciones.
>- **Soluciones no factibles**: Son aquellas soluciones que violan al menos una restricción.
>- **Región factible**: Es el área debajo que se forma bajo todas las funciones de restricción la cual representa al conjunto infinito de todas las soluciones factibles.
>- **Soluciones factibles en los vértices (FEV)**: Son las soluciones que se encuentran en las equinas o vétices de la región factible.
>- **Solución óptima**: Es la solución factible que proporciona el mejor valor para la función objetivo.
### Método Simplex
El método simplex es el más ampliamente utilizado para resolver de manera eficiente los modelos de programación lineal, incluso aquellos modelos de gran tamaño. Este método consiste en un procedimiento algebraico que se repite reiteradas veces hasta alcanzar el resultado.
El proceso de resolución del método simplex consiste en comenzar en el vértice (0, 0) y evalúa si es la mejor solución, si no lo es evalúa si sus vértices adyacentes son la mejor solución. Este proceso se repite hasta llegar a la solución óptima, que generalmente se encuentra en uno de los vértices de la región factible.
>[!tldr] Álgebra del Método Simplex
>El procedimiento algebraico utilizado para resolver un modelo de programación lineal consiste de los siguientes pasos:
>1. Se agregan variables de holgura para convertir las restricciones de desigualdad en restricciones de igualdad, obteniendo una forma aumentada del modelo.
>2. Se utiliza la eliminación de Gauss-Jordan para resolver la matriz resultante.
>
>Para entender esto primero planteamos un modelo de ejemplo. Supongamos que tenemos un modelo cuya función objetivo es la siguiente fórmula:
>$$
>Z = 160x_1 + 100x_2
>$$
>Dicha función está limitada por las siguientes restricciones:
>$$
>\begin{align*}
>2x_1 + x_2 & \leq 6 \\
>2x_1 + 2x_2 & \leq 8 \\
>\end{align*}
>$$
>Para poder resolver esto mediante el método simplex vamos a tener que construir la siguiente matriz:
>$$
>\begin{array}{ccccc|c}
>Z & 160x_1 & 100x_2 & 0x_3 & 0x_4 & 0 \\
>0 & 2x_1 & 1x_2 & 1x_3 & 0x_4 & 6 \\
>0 & 2x_1 & 2x_2 & 0x_3 & 1x_4 & 8 \\
>\end{array}
>$$
>Luego solo se aplica la eliminación utilizando el método de Gauss-Jordan obteniendo el resultado óptimo y los valores de $x_1$ y $x_2$ utilizados para alcanzar dicho óptimo.
### Casos Especiales en la Resolución de los Modelos
Al momento de realizar la resolución de un modelo de programación lineal podemos encontrarnos ante diferentes casos especiales que pueden llegar a ocurrir, entre ellos encontramos:
- **Degeneración**: Normalmente en cada vértice de la región factible, el número de variables básicas es igual al número de restricciones de igualdad, pero puede surgir situaciones donde esas variables básicas sea cero, lo que implica que más de una combinación de restricciones se cruza en el mismo punto. Este fenómeno recibe el nombre de degeneración.
- **Múltiples soluciones óptimas**: En ocasiones puede que un problema tenga varias soluciones óptimas e incluso un número infinito de soluciones.
- **Problemas no acotados**: Esto ocurre cuando las restricciones no impiden que el valor de la función objetivo mejore indefinidamente en la dirección favorable.
- **Problemas sin solución**: En ocasiones puede que las restricciones impuestas a la función objetivo sean contradictorias, esto genera que el problema sea irresoluble. 
## Problema Dual y Análisis de Sensibilidad de los Modelos
Todo problema de programación lineal (primal) tiene asociado otro problema lineal llamado ***problema dual*** o de dualidad. Ambos tipos de problemas están relacionados, ya que la solución óptima de uno proporciona automáticamente la solución óptima al otro. Entre las aplicaciones más importantes de la teoría de la dualidad está la interpretación y realización del análisis de sensibilidad de los modelos.
Para generar un problema dual en base a un modelo de programación lineal específico se debe:
1. Asignar una variable dual $y_i$ por cada restricción primal.
2. Se construye una restricción dual por cada variable $x_j$ que conforma el problema primal.
3. Los coeficientes de restricción (columnas) y el coeficiente objetivo de la variable primal j-ésima definen los lados izquierdo y derecho de la restricción dual j-ésima.
4. Los coeficientes objetivo duales son iguales a los lados derechos de las ecuaciones de restricción primales.
5. Si el modelo de modelo primal es de maximización, el dual será de minimización y viceversa.
6. Si la función objetivo dual es de minimización, entonces todas las restricciones serán del tipo $\geq$ y viceversa.
7. El sentido de la desigualdad cambia:
	- Si el problema primal tienen $\leq$ entonces el dual es $\geq$.
	- Si el problema primal tienen $\geq$ entonces el dual es $\leq$.
	- Si el problema primal tiene $=$ el dual queda con este mismo signo.

Para entender esto con más claridad supongamos que tenemos un problema de programación lineal donde se busca maximizar $Z = cx$, donde $c$ es un vector fila de coeficientes de la función objetivo y $x$ es un vector columna de las variables a optimizar. Esta función está sujeta a $Ax \leq b$ restricciones, donde $A$ es una matriz con los coeficientes que representan las restricciones y $b$ es un vector columna con las disponibilidades de cada variable que conforma el problema.
En este caso, el problema dual buscará minimizar la función $W = yb$, donde $y$ es un vector fila con un nuevo conjunto de variables a optimizar, donde el tamaño del vector $y$ es equivalente a la cantidad de restricciones que posea el modelo primal. Esta función está sujeta a $yA \geq c$ restricciones.
Existe una relación entre la solución de los modelos primales y dales, ya que el resultado óptimo de $W$ corresponde al resultado óptimo de $Z$. Los valores de las variables duales corresponde a los ***costes sombra***, también conocidos como costes de oportunidad del problema primal y viceversa. Este coste sombra representa el aumento o disminución del coste/ganancia por cada unidad extra en la disponibilidad de un material o recurso.
>[!tldr] Teoría de la Dualidad y Análisis de Sencibilidad
>El teorema de la dualidad tiene un papel central el ***análisis de sensibilidad*** de los modelos de programación lineal. Este tipo de análisis tiene como propósito investigar el efecto que tiene sobre la solución óptima, el hecho de hacer cambios en los valores de los parámetros del modelo ($a_{ij}, b_i, c_j$).
>Recordemos que según el *supuesto de certidumbre* todos los parámetros del modelo son constantes conocidas. No obstante, en la realidad esos valores suelen ser generalmente estimaciones realizadas basándose en predicciones de las condiciones futuras, por lo que el análisis de sensibilidad nos ayuda a verificar el efecto que tendrá en el modelo la modificación de los parámetros, esto permite:
>- Identificar los parámetros sensibles.
>- Determinar los ***intervalos de optimalidad*** para los coeficientes dela función objetivo. Estos intervalos nos indica el rango de valores en el cual los coeficientes de la función objetivo puede modificarse para mantener el resultado óptimo.
>- Determinar los ***intervalos de factibilidad*** para el lado derecho de las restricciones. Estos intervalos nos indican el rango de valores por el cual las disponibilidades de las restricciones pueden modificarse para seguir obteniendo el mismo resultado óptimo.
## Modelo de Transporte
Los problemas de transporte son un tipo especial de modelo de programación lineal diseñado para optimizar el envío de mercancías desde varios orígenes hacia varios destinos, minimizando el costo total de transporte.
Este tipo de modelos tienen supuestos y propiedades adicionales que se deben tener en cuenta al momento de plantear este tipo de modelos:
- **Supuesto de requerimientos**: Cada origen tiene un suministro fijo de unidades que se distribuyen entre los destinos y cada destino tiene una demanda fija de unidades que debe ser satisfecha por los orígenes.
- **Supuesto de costo**: El costo de distribuir unidades desde el origen hasta un destino dado es directamente proporcional a la cantidad de unidades distribuidas a dicho destino. Este costo es el costo de distribución multiplicado por la cantidad de unidades distribuidas.
- **Propiedad de solución factible**: Un problema de transporte tiene solución si y solo si la suma de los suministros es igual a la suma de las demandas (modelo balanceado). Si un problema se encuentra desbalanceado, este puede reformularse para poder resolverse.
$$
\sum_{i=1}^{m}S_i = \sum_{j=1}^{n}d_j
$$
- **Propiedad de soluciones enteras**: Si todas las ofertas y demandas de un modelo de transporte tienen valores enteros, los valores óptimos de las variables de decisión también tendrán valores enteros.

>[!tldr] Modelos de Asignación
>Un modelo de asignación es un modelo de transporte en el que la oferta de cada origen y la demanda de cada destino es igual a 1. Este tipo de modelos consiste en asignar de forma óptima $n$ agentes u objetos indivisibles a $n$ tareas, por lo tanto, se asume que:
>1. El número de asignados es igual al número de tareas ($n$).
>2. A cada asignado se le asigna solamente a una tarea.
>3. Cada tarea debe realizarla únicamente por un asignado.
>4. Existe un costo o beneficio $c_{ij}$ asociado con el asignado $i$ que realiza la tarea $j$.
>5. El objetivo es determinar cómo deben hacerse las $n$ asignaciones para minimizar los costos o maximizar los beneficios totales.
>
>De forma general podemos decir que un problema de asignación está conformado por una función objetivo:
>$$
>Z = \sum_{i=1}^{n}\sum_{j=1}^{n}c_{ij}x_{ij}
>$$
>En donde cada $x_{ij} \in \{0, 1\}$ y la función objetivo están sujeta a las siguientes restricciones:
>$$
>\sum_{i=1}^{n}x_{ij} = 1, \ 
>\sum_{j=1}^{n}x_{ij} = 1
>$$
